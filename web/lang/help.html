Help us translate

Every language other than English is a machine draft written by the team's assistant, until a speaker has checked it. Cameroonian languages (Basaa, Ewondo and others) are the hardest: there are few written technical terms, so a draft is only a starting point. If you speak one of these languages, your corrections matter more than anything else on this page.

How to correct a language

  1. Open the file web/lang/<code>.js (for example bas.js for Basaa, ewo.js for Ewondo). Text between quotes is what people read.
  2. Change the words, never the part before the colon (the key), and keep anything in ${...} or {...} exactly as it is: those are numbers filled in by the map.
  3. When a whole file has been checked by a speaker, change status: 'draft' to status: 'reviewed'. The yellow "draft" note then disappears for that language.
  4. A string you leave out falls back to the language named in fallback (French for Cameroonian languages, then English), so a partly translated file still works.

How to add a language

  1. Copy web/lang/en.js to web/lang/<code>.js using the language's ISO 639 code, and rename LANGS.en inside it.
  2. Add one line to web/lang/registry.js: { code: 'bas', name: 'Ɓasaá' } (add dir: 'rtl' for right-to-left scripts).
  3. Translate. Reload the map and pick the language in the menu.
LANGS.bas = {
  meta: { name: 'Ɓasaá', status: 'draft', fallback: ['fr', 'en'] },
  index: { title: '…', mterrain: '…' },   // only what you have translated
  globe: { title: '…' },
  common: { langlabel: '…', draftnote: '…', draftlink: '…' }
};

The pages sources.html and the documentation stay in English for now.
